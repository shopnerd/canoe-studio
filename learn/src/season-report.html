Template · Fill in after each competition

Season report

The same questions every year, so each team can see what changed and why. Fill it in within a week of the Symposium and again after Finals, while the judges’ comments and race times are fresh.

How to use it. Type straight into the page. It saves in this browser as you go, and totals and gaps calculate themselves. When you’re done, Download a Markdown file (it opens in Google Docs or any text editor) and put it in the team Drive next to last year’s. Nothing you type is sent anywhere.
