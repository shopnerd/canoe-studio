Using Canoe Studio

Canoe Studio is a browser version of the team’s Grasshopper hull script. You shape four control curves, and it lofts the hull, builds the concrete shell and mold, and checks how the boat floats, how stable it is, and whether it meets the 2027 rules.

The workflow

  1. Set the envelope. In the left panel, start with Hull envelope: length, beam and depth. Everything else is measured inside that box.
  2. Shape the curves. On the Curves tab, drag the orange handles on the cross section, the profile (keel, stem and sheer) and the plan view. Each curve must stay inside its dashed box. That’s the same check the Grasshopper script runs, and a curve that leaves its box turns red.
  3. Read the analysis. About a second after you stop dragging, the Analysis tab updates: weight, draft, freeboard, stability and speed.
  4. Check the rules. The Rules 2027 tab shows pass, close or fail for each rule the geometry can check, plus the structural load case the report requires.
  5. Export. Build & export produces section templates, hot-wire templates, an offsets table, STL files and the design file.

What each tab tells you

Curves

Four 2D editors: cross section at midship, profile of the bow half (keel rocker, stem and the sheer line in blue), plan (the gunwale seen from above), and a body plan of true cross-sections sliced from the finished hull. Use Vertical scale to exaggerate heights when a curve is hard to read. The waterline at race load is drawn once the analysis runs.

Analysis

  • Hull weight comes from the concrete volume × the unit weight you set in Analysis inputs.
  • Draft and freeboard are computed at your race load: the paddlers plus the hull plus other weight. Freeboard is measured at the lowest point of the gunwale.
  • GM is the stability number. Bigger means stiffer; zero or negative means it rolls over upright. The righting-arm (GZ) curve shows stability as the canoe heels, and marks where the gunwale reaches the water.
  • Form coefficients (Cb, Cp, Cm, Cwp) describe how full the hull is. The sectional area curve shows how volume is spread from stern to bow.
  • Speed & drag gives theoretical hull speed and skin-friction drag only. Wave drag isn’t included, so use it to compare designs, not to predict race times.
  • Pin as baseline freezes the current numbers, so every card afterwards shows the change from that design. Use it before trying an idea.

Rules 2027

Hull thickness, names above water with four paddlers, the swamp test, a foam plan that sizes the bow and stern bulkheads so the swamped hull floats with a margin and checks that the foam fits within 3 ft of the ends, concrete unit weight, reinforcement ratio and open area, and the 3-person structural load case with moment, shear, section properties, stresses and punching shear. See the rules guide for what each one means.

Sharing and saving

  • Copy link puts every changed parameter into the web address. Send it and the other person opens the exact same hull.
  • Save / Open writes and reads a design file. Name the design first (top left) so the files are easy to tell apart.
  • The app also remembers your last design in this browser automatically. Reset returns to the values in the original Grasshopper file, and Undo (Ctrl+Z) steps back.

What the model assumes

  • Fresh water. Paddlers are modeled as point weights on the centerline at the CG height you set.
  • Strengths (f′c and composite tensile) are placeholders until the team has cylinder and flexural test data. The structural check is only as good as those two inputs.
  • A few details of the original script were ambiguous and were interpreted, such as the sheer tangent and which shell faces are removed. The repository README lists them. Compare against a baked Rhino result before trusting small differences.
  • Analysis is an early-design estimate. The float test is the real answer.
